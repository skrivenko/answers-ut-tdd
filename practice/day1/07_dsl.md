### Практика. Упражнение про кассовый чек

```  
Наименование товара         Кол-во         Цена            Стоимость   
  
Ноутбук                       2        45000.00 руб       90000.00 руб
Мышь                          3         1500.00 руб        4500.00 руб
......................................................................
Итого                                                     94500.00 руб
Скидка 15%                                               -14175.00 руб
Налог NV 8.0%                                             +6426.00 руб
......................................................................
Общая сумма                                               86751.00 руб
```  

Мы производим кассовый аппарат, способный выдавать чеки.
Принимает от пользователя 4 параметра для одного или нескольких товаров:
 - Название
 - Количество 
 - Цена
 - Буквенный код штата

По общей цене без налога мы можем рассчитать скидку.                          
| Сумма заказа | Ставка скидки |
| --- | --- |
| > 1000 | 3% |
| > 5000 | 5% |
| > 7000 | 7% |
| > 10000 | 10% |
| > 50000 | 15% |

По заданным 2-буквенным кодам штата мы можем рассчитать ставку налога.
| Штат | Ставка налога |
| --- | --- |
| UT | 6,85% |
| NV | 8,00% |
| TX | 6,25% |
| AL | 4,00% |
| CA | 8,25% |
   
### Тесты на кассовый чек
    
Придумать, какие нужны тесты
  - Печатаем пустой чек
  - Печатаем чек с одним товаром в количестве 1 шт и ценой меньше 1000
  - Печатаем чек для одного товара в количестве нескольких штук и суммой меньше 1000
  - Печатаем чек для нескольких товаров по несколько штук и суммой меньше 1000
  - Печатаем чек с суммой 2000 для скидки в 3%
  - ...
  - Печатаем чек для штата UT с ненулевой скидкой
  - ...
  
Подумать, как могут выглядеть DSL-style тесты

#### Пример без DSL

```python
order = Order()
order.add_line_item(
    "Laptop",
    2,
    Rub(45000.00),
)
order.add_line_item(
    "Mouse",
    3,
    Rub(1500.00),
)
order.set_state("NV")
receipt = order.get_receipt()

assert receipt.total() == Rub(86751.00)
```

#### Пример DSL
```python
receipt = Create.receipt().for_order(
    Create.order_line_item(2, "Laptop").with_price(Rub(45000.00)).please(),
    Create.order_line_item(3, "Mouse").with_price(Rub(1500.00)).please(),
).in_state("NV").please()

assert receipt.total() == Rub(86751.00)
```
