Здесь находится только финальная версия. Если хочется проследить разработку по шагам, можно посмотреть вот тут: https://github.com/nchursin/ut-tdd-exercises/compare/main...04_solution

## ВНИМАНИЕ!

В решении показано использование трёх разных типов рефакторинга для иллюстрации нескольких концептов.

В `Receipt` применён шов через наследование.

В `update_receipts` применён slice с пробрасыванием зависимости в метод.

В `generate_receipt_report` применён slice с пробрасыванием зависимости в экземпляр объекта.

В продакшн коде НЕ РЕКОМЕНДУЕТСЯ мешать последние 2 типа внтри одного модуля, так как это приводит к снижению тестироуемости. В данном упражнении это сделано ИСКЛЮЧИТЕЛЬНО только для иллюстрации концептов.
